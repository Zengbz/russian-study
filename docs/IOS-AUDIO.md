# iPhone 静音模式播放兼容补丁 v2.2

本补丁针对“iPhone开着静音时，点发音没有声音”的情况。支持Audio Session API的浏览器会在每次点播放时请求`playback`类型，然后立即播放固定录音或系统朗读；结束、打断或失败后恢复先前的类型。不支持该接口或设置失败时沿用原播放方式。

这是兼容处理。浏览器的API支持、系统俄语声音、输出设备和系统音频会话仍会影响结果。尤其词句使用的`SpeechSynthesis`由系统管理，不能根据一次API调用成功就断言用户实际听到了声音。本补丁尚未在真实iPhone上验证静音开关效果。

## 上传

将`ios-audio-update.zip`解压后的文件覆盖到俄语应用原位置，再提交。包内文件为：

- `audio.js`：两条播放路径共用的媒体播放会话请求与释放。
- `index.html`：加载v2.2脚本，并在声音设置中显示版本说明。
- `sw.js`：更新外壳缓存版本，保留课程缓存。
- `tests/course.test.cjs`、`tests/audio-session.test.cjs`：更新缓存版本断言，加入会话兼容测试。
- `docs/IOS-AUDIO.md`：本说明。

等待发布成功后，联网打开应用，在“…”中点“检查新课程与应用更新”，随后完全关闭并重新打开PWA。声音设置中看到“v2.2”说明后再测试。课程和进度使用原有文件与存储键，本补丁不包含或修改周课程。

## 手机上核对

1. 保持iPhone静音，打开适当的媒体音量。
2. 在33字母表点击М的基本音值，测试固定录音。
3. 在声音设置中试听Привет，再在课程内点一句话，测试系统朗读。
4. 连点同一项应重新播放，点另一项应切换；切回应用后再次点击应能重试。

如果固定录音能听到、词句仍无声，说明两条声音路径表现不同；可暂时关闭静音听系统朗读，并记录iOS版本与Safari／桌面PWA的区别，便于后续定位。页面无法直接检测静音开关或确认扬声器实际有声。

## 验证与依据

自动检查覆盖：播放前同步请求、固定录音与系统朗读两条路径、缺失／被拒绝的API、结束／打断／失败恢复、旧回调隔离、避免覆盖外部会话类型；原有课程、进度、录音和缓存检查继续运行。模拟测试不等于iPhone实机静音测试。

- [WebKit关于静音与媒体播放模式的说明](https://bugs.webkit.org/show_bug.cgi?id=237322#c6)：该条讨论的是Web Audio，可确认媒体会话的处理方向，不能据此保证所有系统朗读行为。
- [W3C Audio Session草案](https://www.w3.org/TR/audio-session/)：网页音频会话的类型与焦点规则。
- [Apple playback类别说明](https://developer.apple.com/documentation/avfaudio/avaudiosession/category-swift.struct/playback)：原生媒体播放类别与静音开关的关系；PWA仍以浏览器实际行为为准。
