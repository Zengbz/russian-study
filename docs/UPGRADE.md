## 第一次升级

1. 在旧应用右上角设置中先“导出学习记录”，保留备份。
2. 解压完整安装包，打开 `russian_90_day_pwa` 文件夹。把里面的内容上传到俄语应用自己的 GitHub 仓库根目录，覆盖同名文件。网页每次最多上传100个文件，本包带录音，建议分两批：先单独上传整个 `assets` 文件夹并提交，再上传其余文件和目录并提交。不要把外层文件夹或 ZIP 本身作为网页上传。
3. 检查仓库中存在 `.github/workflows/pages.yml`、`scripts/build.mjs`、`tests/`、`assets/` 和 `courses/week1-course.json` 至 `week4-course.json`。如果网页上传没有带上 `.github`，用 GitHub 的 Add file → Create new file 新建 `.github/workflows/pages.yml`，粘贴安装包里的同名文件内容。
4. 打开仓库 Settings → Pages，将 Source 改为 **GitHub Actions**。
5. 在 Actions 中找到 “Publish Russian pocket course”。提交文件后会自动运行；如果首次设置时已经错过触发，打开该工作流，点 Run workflow。等发布成功后访问 Pages 地址。
6. 手机关闭旧页面再重新打开；右上角“…”点“检查新课程与应用更新”。本次会切换应用外壳；若仍显示“俄语90天”，退出主屏幕应用后再联网打开一次。必要时在保留备份后重新添加主屏幕快捷方式。

进度沿用旧版存储键和第一周题目编号。同一个网站地址、同一个浏览器下应自动保留；换仓库、域名或浏览器，需要用备份“导入学习记录”。导入同课记录时采用备份内容，可在设置中撤销上一次导入。没有跨设备自动同步。

**如果原仓库还承载另一个 Pages 网站，请使用单独的俄语仓库。** 包内工作流会发布整个俄语站点；要放在现有站点子目录，应把俄语静态文件合并进原站点的发布产物，并统一发布工作流。不要用两个工作流轮流覆盖同一个 Pages 站点。

## 以后添加第5周、第6周……

首次升级完成后，新增课程只需：

1. 打开仓库的 `courses` 文件夹。
2. 上传新文件，例如 `week5-course.json`，提交到仓库默认分支。
3. 等待 Actions 检查、生成目录并发布成功。
4. 在手机的“…”中点“检查新课程与应用更新”，首页的周选择器会出现新课程。

文件名采用 `week1-course.json`、`week2-course.json`……，不补前导零，也没有最大周数。新课的全局课号、题号应唯一，例如第5周一般使用第29—35课，题号 `d29-q01` 等。编号出现空缺不会阻止识别。

**不用手动更新 `catalog.json`，不用每次重传程序。** 工作流会扫描所有周文件，校验内容并在发布产物中生成带内容校验值的目录。仓库里附带的目录是本次版本快照，后续发布会自动重建。

只有使用既有题型和朗读方式时，才只需上传 JSON。新增图片、录音时还需上传对应资源；新增题型或功能时需升级程序。发布失败时查看 Actions 的报错，修正相应周文件；先前发布成功的版本仍可继续使用。

## 新功能怎么用

- **33字母表**：“…” → “33个字母表”。点大字听音值，另有字母名称和例词。辅音音值片段连播3次，展开可听完整带读参考；Ь、Ъ播放符号名称。清浊分类按字母常见音值，具体词中的变音随课学习。
- **朗读**：重复点击从头播放，点其他内容切换。播放期间喇叭有动态声波；启动超时会提示重试，按钮保持可操作。词句使用设备俄语语音，字母音值使用附带音频。音值参考是国际音标录音的教学剪辑，并非所有俄语语境和软硬音的完整录音库。
- **写**：第2、3周每课3道，第4周每课3—4道键盘题，包括看词输入热身、中文提示拼写、填空式提示和听写。提交后自动判定，错误位置高亮，可继续订正；首次作答保持不变。看词输入热身不计入独立正确率。
- **判题宽容度**：默认忽略大小写、多余空格、学习用重音、句末句号问号叹号；默认区分Е／Ё、И／Й、Ь／Ъ。混入英文字母时先提示更换键盘，不计该次提交。题目可配置允许的答案变体和更严格规则。
- **复习5题**：直接练错项、用过提示的题和待练听力。复习成绩独立保存，不覆盖整课首次成绩。复习正确后按1、3、7天的初始规则安排再次出现。
- **学习卡片**：分为字母与拼读、实用表达、句子与要点三个短段；保存已选段落。首页“继续”会优先恢复最近未完成课程的答题位置。
- **重音显示**：随应用附带支持西里尔组合重音的字体，把俄语单词作为整体换行。输入重音仍可省略。此修改已在手机尺寸浏览器预览核对，真实iPhone系统字体、键盘、声音表现仍需实机体验。

## 手机键盘与离线使用

iPhone：设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → 俄语。输入时长按地球图标切换。输入框会保存未提交的草稿。

首页“下载本周＋字母音频”保存这一周文字和固定字母音频；已访问的课程也会自动缓存。未下载的周在离线时会提示联网。**词句朗读离线可用与否，取决于手机是否有本地俄语声音**；应用不能把系统语音导出成音频缓存。没有声音时可用文字辅助，听力会保留待练标记。
