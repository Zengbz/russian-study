# 俄语旅行口袋课：本次升级与以后添加课程

## v3.0：语法专项与可追加模块

本次新增首页“语法专项”，6个分类、36个专题、288项练习（72道键盘输入题）。不按天解锁，所有专题可自由选择；每页6个专题。每节包括规则、词形表、3个可点读例句、8项练习，支持中途继续、输入草稿、订正、首次成绩与重练记录。专项完成不计入每日课程数或打卡天数。

### 已有前90课版本：这次上传更新包

1. 在原应用“…”中导出学习记录。
2. 解压 `grammar-module-update.zip`，将包内文件和文件夹合并到俄语应用原目录，覆盖同名文件并提交。不要把 ZIP 文件直接上传成网页，也不要额外套一层文件夹。保留原有 `courses/`、`assets/` 和后来添加的内容。
3. 确认仓库包含 `modules.js`、`module-ui.js`、`modules/grammar/module.json`、6个分类 JSON、`modules/catalog.json`，以及本次更新的 `scripts/build.mjs`。这些文件应与更新后的 `index.html` 一起发布，避免漏传导致白屏。
4. Settings → Pages → Source 选择 **GitHub Actions**，确认使用包内 `.github/workflows/pages.yml`。等待 “Publish Russian pocket course” 成功。
5. 手机“…” → “检查新课程与应用更新”，完全关闭 PWA 后重新打开；设置中的声音说明显示 **v3.0**，首页出现“语法专项”。不需要清除网站数据。

第一次安装或更早版本，可改用最新完整包：把 `russian_90_day_pwa/` 内的文件合并上传。更新包和完整包选择一种即可，无需都上传。更换网址或浏览器前先导出进度，之后导入。

### 以后添加新模块

例如增加“旅行专项”，只需上传这一组文件：

- `modules/travel/module.json`：模块名称、简介、排序、编号。
- `modules/travel/transport.json`：交通分类及其专题。
- `modules/travel/hotel.json`：住宿分类及其专题。

提交默认分支，配套 Actions 会扫描文件夹，校验内容、生成 `modules/catalog.json`，自动增加首页入口、分类、专题和分页。**使用配套 Actions 时无需手改 catalog，也不用重新上传全站。** 更新某个模块不要求修改其他模块。给已有语法模块增添分类时，只上传例如 `modules/grammar/new-category.json`；给分类加专题时，只更新该分类 JSON。

如果使用 “Deploy from a branch”，GitHub 不会运行本包的目录扫描脚本；必须同时上传重新生成的 `modules/catalog.json`，否则新模块不会出现在首页。要实现只上传新模块文件，请切换到上述 Actions。构建目录只更新发布产物，不回写源码仓库，因此仓库里的旧快照不代表线上目录仍旧。

讲解、表格、俄中例句和现有6种题型都走通用模块引擎。新录音需一起上传到模块的 `assets/`；全新题型、复杂交互或后端功能仍需升级引擎。模块结构、可复制示例、稳定编号与校验规则见包内 `docs/MODULE-FORMAT.md`。

### 记录与离线

原来的每日课号、题号与存储键保持不变。所有模块在独立命名空间保存，首页每日“继续”不会被专题取代；专题有单独的“继续上次专题”。导出的备份含每日和所有模块，旧版备份可导入，未出现在备份里的模块记录会保留。同一专题导入时采用备份内容，可撤销上一次导入。

分类中“下载本分类”保存该分类文字、题目和引用的固定录音。已访问分类也会缓存；从未下载的分类离线不可打开。词句朗读仍需设备俄语声音，离线还需本地声音。语法例句使用系统朗读，没有新增真人录音。

## 第一次升级

1. 在旧应用右上角设置中先“导出学习记录”，保留备份。
2. 解压完整安装包，打开 `russian_90_day_pwa` 文件夹。把里面的内容上传到俄语应用自己的 GitHub 仓库根目录，覆盖同名文件。网页每次最多上传100个文件，本包带录音，建议分两批：先单独上传整个 `assets` 文件夹并提交，再上传其余文件和目录并提交。不要把外层文件夹或 ZIP 本身作为网页上传。
3. 检查仓库中存在 `.github/workflows/pages.yml`、`scripts/build.mjs`、`tests/`、`assets/` 和 `courses/week1-course.json` 至 `week13-course.json`。如果网页上传没有带上 `.github`，用 GitHub 的 Add file → Create new file 新建 `.github/workflows/pages.yml`，粘贴安装包里的同名文件内容。
4. 打开仓库 Settings → Pages，将 Source 改为 **GitHub Actions**。
5. 在 Actions 中找到 “Publish Russian pocket course”。提交文件后会自动运行；如果首次设置时已经错过触发，打开该工作流，点 Run workflow。等发布成功后访问 Pages 地址。
6. 手机关闭旧页面再重新打开；右上角“…”点“检查新课程与应用更新”。本次会切换应用外壳；若仍显示“俄语90天”，退出主屏幕应用后再联网打开一次。必要时在保留备份后重新添加主屏幕快捷方式。

**如果原仓库还承载另一个 Pages 网站，请使用单独的俄语仓库。** 包内工作流会发布整个俄语站点；要放在现有站点子目录，应把俄语静态文件合并进原站点的发布产物，并统一发布工作流。不要用两个工作流轮流覆盖同一个 Pages 站点。

## 以后添加第14周、第15周……

已将Pages Source设为GitHub Actions，并确认“Publish Russian pocket course”工作流成功运行后，新增课程只需：

1. 打开仓库的 `courses` 文件夹。
2. 上传新文件，例如 `week14-course.json`，提交到仓库默认分支。
3. 等待 Actions 检查、生成目录并发布成功。
4. 在手机的“…”中点“检查新课程与应用更新”，首页的周选择器会出现新课程。

文件名采用 `week1-course.json`、`week2-course.json`……，不补前导零，也没有最大周数。新课的全局课号、题号应唯一，例如第14周一般使用第91—97课，题号 `d91-q01` 等。编号出现空缺不会阻止识别。

**网站必须拿到更新后的 `catalog.json`。启用配套Actions时，由工作流自动更新，无需手改。** 工作流扫描所有周文件，在发布产物中生成目录；它不会把生成结果提交回仓库，因此仓库文件仍是旧快照不一定表示线上目录旧。

如果Pages使用“Deploy from a branch”，它会发布所选分支、目录中的静态文件，不能依赖本包自定义构建步骤自动生成目录。这种模式需要每次连同新周JSON上传匹配的 `courses/catalog.json`，或在本地运行 `node scripts/build.mjs` 后上传生成的目录。要实现以后只上传weekN文件，请改为配套Actions发布。

只有使用既有题型和朗读方式时，才只需上传 JSON。新增图片、录音时还需上传对应资源；新增题型或功能时需升级程序。发布失败时查看 Actions 的报错，修正相应周文件；先前发布成功的版本仍可继续使用。

## 新功能怎么用

- **33字母表**：“…” → “33个字母表”。点大字听音值，另有字母名称和例词。辅音音值片段连播3次，展开可听完整带读参考；Ь、Ъ播放符号名称。清浊分类按字母常见音值，具体词中的变音随课学习。
- **朗读**：重复点击从头播放，点其他内容切换。播放期间喇叭有动态声波；启动超时会提示重试，按钮保持可操作。词句使用设备俄语语音，字母音值使用附带音频。音值参考是国际音标录音的教学剪辑，并非所有俄语语境和软硬音的完整录音库。
- **写**：第2、3周每课3道，第4周每课3—4道，第5—12周每课4道、第13周共25道键盘题，包括看词输入热身、中文提示拼写、填空式提示和听写。提交后自动判定，错误位置高亮，可继续订正；首次作答保持不变。看词输入热身不计入独立正确率。
- **判题宽容度**：默认忽略大小写、多余空格、学习用重音、句末句号问号叹号；默认区分Е／Ё、И／Й、Ь／Ъ。混入英文字母时先提示更换键盘，不计该次提交。题目可配置允许的答案变体和更严格规则。
- **复习5题**：直接练错项、用过提示的题和待练听力。复习成绩独立保存，不覆盖整课首次成绩。复习正确后按1、3、7天的初始规则安排再次出现。
- **学习卡片**：分为字母与拼读、实用表达、句子与要点三个短段；保存已选段落。首页“继续”会优先恢复最近未完成课程的答题位置。
- **重音显示**：随应用附带支持西里尔组合重音的字体，把俄语单词作为整体换行。输入重音仍可省略。此修改已在手机尺寸浏览器预览核对，真实iPhone系统字体、键盘、声音表现仍需实机体验。

## 最后6课的使用方式

第85课有12道客观诊断题和3项口头任务。按错项领域手动记下三个优先复习点；应用的“复习5题”仍按已有错项安排。第89课提供数字、位置、需求三组固定迁移训练，当前不自动按诊断分数生成个性化题包。

第90课有16道客观题、4个场景短回答和1项约60秒自述。客观题至少13／16，场景至少3／4为阶段最低目标；应用通用的“已掌握”标记仍要求全部口语任务独立完成。口语和听力文字辅助不冒充自动评测成绩。完成本阶段不等于A1认证。

## 手机键盘与离线使用

iPhone：设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → 俄语。输入时长按地球图标切换。输入框会保存未提交的草稿。

首页“下载本周＋字母音频”保存这一周文字和固定字母音频；已访问的课程也会自动缓存。未下载的周在离线时会提示联网。**词句朗读离线可用与否，取决于手机是否有本地俄语声音**；应用不能把系统语音导出成音频缓存。没有声音时可用文字辅助，听力会保留待练标记。
