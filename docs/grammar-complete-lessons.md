# 语法入门

## 词类与句子成分（基础）

找出谁、做什么、什么样，读懂最短俄语句子。

### 用途与规则

词类是词本身的类别，句子成分是它在具体句子里的作用。先识别名词、动词、形容词和代词。现在时介绍身份或物品时，通常不另加一个“是”。

| 情境／基本形式 | 本节用法／词形 | 说明 |
|---|---|---|
| па́спорт | 名词 | 表示护照这一物品 |
| чита́ть | 动词原形 | 表示读这一动作 |
| но́вый | 形容词 | 描述新的 |
| я | 人称代词 | 表示我 |
| Я чита́ю. | 主语＋动作 | я是我，читаю是我读 |

### 读懂，再开口

先听完整例句，再留意本节的词形和搭配。能看懂后，遮住例句回忆。新词的意思随中文例句给出。

- Я чита́ю. — 我在读书。

- Э́то па́спорт. — 这是护照。

- Па́спорт но́вый. — 护照是新的。

### 常见错误与学习范围

不要按中文逐词加“是”：Я есть турист不是本节介绍身份的常用句型。本节只做词类与短句辨认，不展开完整句法。

## 名词的性（基础）

用名词本身的性选择мой、моя、моё。

### 用途与规则

俄语名词有阳性、阴性、中性。词尾常提供线索，但不是绝对规则。形容词和归属词跟物品名词配合，不跟说话者的性别配合。

| 情境／基本形式 | 本节用法／词形 | 说明 |
|---|---|---|
| па́спорт | 阳性 | 本节用мой паспорт |
| ка́рта | 阴性 | 本节用моя карта |
| ме́сто | 中性 | 本节用моё место |
| оте́ль | 阳性 | 以软音符号结尾，需连同性记 |
| и́мя | 中性 | 不是所有-я结尾词都为阴性 |

先听完整例句，再留意本节的词形和搭配。能看懂后，遮住例句回忆。新词的意思随中文例句给出。

## 名词的单复数（基础）

辨认一件与多件，并跟着复数调整归属词。

### 用途与规则

常见名词复数会改变词尾，部分词重音也变化。不能统一加同一个词尾。介绍多个物品仍可以用Это…，后面的名词和归属词用复数形式。

| 情境／基本形式 | 本节用法／词形 | 说明 |
|---|---|---|
| су́мка | су́мки | 包，к后本例写и |
| ко́мната | ко́мнаты | 房间 |
| биле́т | биле́ты | 票 |
| стол | столы́ | 桌子，重音移到词尾 |
| стул | сту́лья | 椅子，特殊变化 |

## 疑问与否定（基础）

区分问人、问物、问地点，并把не放到要否定的部分前。

### 用途与规则

кто问谁，что问什么，где问在哪里。一般疑问句可保留陈述语序，用疑问语调表示。не通常放在需要否定的词语前；нет也可作独立的“不”回应。

| 情境／基本形式 | 本节用法／词形 | 说明 |
|---|---|---|
| Кто э́то? | 这是谁？ | 问人 |
| Что э́то? | 这是什么？ | 问物 |
| Где оте́ль? | 酒店在哪里？ | 问位置 |
| Я не понима́ю. | 我不明白。 | не在动词前 |

### 读懂，再开口

先听完整例句，再留意本节的词形和搭配。能看懂后，遮住例句回忆。新词的意思随中文例句给出。

- Кто э́то? — 这是谁？

- Вы говори́те по-ру́сски? — 您会说俄语吗？

не与нет不是处处可互换：Я не понимаю，不说Я нет понимаю。这里不展开否定代词，也不把语调简化成每句话末尾都上扬。

# 名词、格与介词

## 主格：介绍与拥有（基础）

识别基本形式，说明这是什么、谁在做事、有什么。

### 用途与规则

主格常用于给事物命名、作主语，或在拥有句中表示所拥有的物品。本节先比较Это вода与У меня есть вода，名词都用基本形式。

| 情境／基本形式 | 本节用法／词形 | 说明 |
|---|---|---|
| па́спорт | Э́то па́спорт. | 介绍护照 |
| вода́ | У меня́ есть вода́. | 拥有句中的物品 |
| Анна | А́нна чита́ет. | 安娜是动作的发出者 |
| биле́ты | Э́то биле́ты. | 介绍多个物品 |

### 读懂，再开口

先听完整例句，再留意本节的词形和搭配。能看懂后，遮住例句回忆。新词的意思随中文例句给出。

- Э́то вода́. — 这是水。

- У меня́ есть биле́т. — 我有票。

- А́нна чита́ет. — 安娜在读书。

### 常见错误与学习范围

不要把拥有句里的物品直接改成宾格：У меня есть вода，不是есть воду。本节只列主格的常见功能，不要求背所有定义。

## 宾格：动作对象（基础）

用熟悉名词表达想要什么，并认识人的宾格。

### 用途与规则

宾格常表示动作直接涉及的人或物。常见阴性-а变-у；阳性非动物名词通常与主格同形。阳性单数动物性名词常与属格同形，本节用студент作示例。

| 情境／基本形式 | 本节用法／词形 | 说明 |
|---|---|---|
| вода́ | во́ду | 想要水：хочу воду |
| ка́рта | ка́рту | 要一张卡：дайте карту |
| биле́т | биле́т | 阳性非动物名词，本例同形 |
| студе́нт | студе́нта | вижу студента：看见学生 |

### 读懂，再开口

先听完整例句，再留意本节的词形和搭配。能看懂后，遮住例句回忆。新词的意思随中文例句给出。

- Я хочу́ во́ду. — 我想要水。

- Я ви́жу студе́нта. — 我看见一名男学生。

- Да́йте ка́рту, пожа́луйста. — 请给我一张卡。

### 常见错误与学习范围

不能把-а→-у套给所有词。Я вижу中的вижу表示“我看见”；这里只练已给名词的单数形式，暂不扩展动物性复数。

### 练习与答案

选项：хочу вода ／ хочу воде ／ хочу воду

答案／参考：хочу воду

解析：动作对象使用宾格воду。

**2. 看见一名男学生，使用？**（choice）

选项：вижу студентом ／ вижу студента ／ вижу студент

答案／参考：вижу студента

解析：阳性单数动物性名词студент的宾格为студента。

**3. 要一张票，使用？**（choice）

选项：Дайте билет. ／ Дайте билетом. ／ Дайте билету.

答案／参考：Дайте билет.

解析：билет为非动物性名词，宾格与主格同形。

**4. 只填空缺词：Я хочу ___ .（我想要水。）**（input）

答案／参考：воду

解析：宾格为воду。

**5. 按本节例句的用词和语序输入：“请给我一张卡。”**（input）
