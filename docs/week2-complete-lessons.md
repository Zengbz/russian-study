# 第2周：读懂33个字母

补齐字母、重音与硬软音；开始键盘拼写和听写

## 第8课：第六组字母与旅行物品

认识4个新字母；能区分要茶和要账单。

### 学习卡片

只拼读已学字母：ша — жа — ча；шар（球）、жар（热）、чай（茶）。长词先整体听说。

- чай：茶。重音已标出；听后跟读，再回忆中文。
- счёт：账单。先整词听说；сч读音接近长软擦音，Ё在下一课介绍。
- бага́ж：行李。词尾Ж清化，听起来接近Ш；拼写仍为Ж。
- пло́щадь：广场。先整词听说；Ь在第10课介绍。

- Чай, пожа́луйста.：请给我茶。
- Счёт, пожа́луйста.：请结账。

- Ж、Ш通常是硬音，Ч、Щ通常是软音。
- Ш和Щ要分别听；Щ通常更长、舌位不同。
- 字母名Ж是же，字母音值示范与名称分开。

### 练习与答案

1. 【match】配对今天4个字母的大小写。
   - 答案／参考：Ж ↔ ж；Ш ↔ ш；Ч ↔ ч；Щ ↔ щ
   - 解析：逐项对应后再读一遍。

2. 【choice】哪个字母通常表示较长的软擦音？
   - 选项：Ш / Щ / Ж
   - 答案／参考：Щ
   - 解析：Щ通常表示[ɕː]，不要和Ш混为一谈。

3. 【choice】哪个字母通常表示清辅音[ʂ]？
   - 选项：Ш / Ж / Ч
   - 答案／参考：Ш
   - 解析：Ш是清辅音，Ж是与它成对的浊辅音。

4. 【choice】你想喝茶，应选哪一个词？
   - 选项：чай / багаж / счёт
   - 答案／参考：чай
   - 解析：чай表示茶。

5. 【choice】用餐后想结账，选哪句话？
   - 选项：Чай, пожалуйста. / Счёт, пожалуйста. / Где метро?
   - 答案／参考：Счёт, пожалуйста.
   - 解析：Счёт, пожалуйста.是简短的结账请求。

6. 【listen】听这句请求，对方想要什么？
   - 朗读内容（听力先隐藏）：Чай, пожа́луйста.
   - 选项：茶 / 账单 / 行李
   - 答案／参考：茶
   - 解析：Чай是茶，пожалуйста在这里表示请。

7. 【listen】听这句请求，对方想要什么？
   - 朗读内容（听力先隐藏）：Счёт, пожа́луйста.
   - 选项：茶 / 账单 / 广场
   - 答案／参考：账单
   - 解析：Счёт是账单。

8. 【listen】听这个词，选择意思。
   - 朗读内容（听力先隐藏）：бага́ж
   - 选项：行李 / 茶 / 银行
   - 答案／参考：行李
   - 解析：багаж是行李；末尾Ж会清化。

9. 【input】看着词输入，熟悉俄语键盘。
   - 答案／参考：чай
   - 解析：依次输入ч、а、й；Й不是И。

10. 【input】把“茶”写成俄语。
   - 答案／参考：чай
   - 解析：чай以Й结尾，不是И。

11. 【input】把“行李”写成俄语。
   - 答案／参考：багаж
   - 解析：尽管词尾声音清化，拼写保留Ж。

12. 【order】排列“请给我茶”。
   - 答案／参考：Чай, пожалуйста.
   - 解析：物品名后加пожалуйста，是简短礼貌请求。

13. 【choice】багаж末尾听起来接近Ш，应该把拼写改成Ш吗？
   - 选项：是，改成Ш / 不，仍写Ж
   - 答案／参考：不，仍写Ж
   - 解析：词尾清化改变读音，并不直接改变拼写。

14. 【oral】你在咖啡馆：先要茶，用餐后再请求结账。
   - 答案／参考：Чай, пожа́луйста.；Счёт, пожа́луйста.
   - 解析：说完再对照参考；名字可以换成自己的。

## 第9课：第七组字母与元音

分清Е和Ё；能请求菜单或再说一次。

### 学习卡片

я — моя́ — моё；ме́ню；ещё。试着找到重音；Ё上的两点不是可随意省略的练习标记。

- я：我。重音已标出；听后跟读，再回忆中文。
- ещё：再／还。Ё通常重读；这里表示再。
- моё：我的。先记语块，后面学习它与中性名词的搭配。
- ме́ню：菜单。重音在Е，不在Ю。

- Ещё раз, пожа́луйста.：请再说一遍。
- Ме́ню, пожа́луйста.：请给我菜单。

- Е、Ё是不同字母，拼写练习默认区分。
- Е、Ё、Ю、Я在词首等位置常包含[j]；辅音后通常提示软化。
- 当前只掌握常见读法，随例词逐步巩固。

### 练习与答案

1. 【match】配对今天4个字母的大小写。
   - 答案／参考：Ё ↔ ё；Ю ↔ ю；Я ↔ я；Э ↔ э
   - 解析：逐项对应后再读一遍。

2. 【choice】哪一个字母是Ё的小写？
   - 选项：е / ё / э
   - 答案／参考：ё
   - 解析：ё保留上方两点。

3. 【choice】я通常表示什么？
   - 选项：我 / 你 / 他
   - 答案／参考：我
   - 解析：я是第一人称单数。

4. 【choice】哪个词表示菜单？
   - 选项：меню / метро / багаж
   - 答案／参考：меню
   - 解析：меню表示菜单。

5. 【choice】菜单ме́ню的重音在哪个元音？
   - 选项：Е / Ю / 没有重音
   - 答案／参考：Е
   - 解析：ме́ню重读第一音节。

6. 【listen】听这句请求，选择意思。
   - 朗读内容（听力先隐藏）：Ме́ню, пожа́луйста.
   - 选项：请给我菜单 / 请结账 / 请给我茶
   - 答案／参考：请给我菜单
   - 解析：Ме́ню表示菜单。

7. 【listen】对方希望你怎么做？
   - 朗读内容（听力先隐藏）：Ещё раз, пожа́луйста.
   - 选项：再说一次 / 马上离开 / 介绍姓名
   - 答案／参考：再说一次
   - 解析：Ещё раз表示再一次。

8. 【listen】听这个词，选相同拼写。
   - 朗读内容（听力先隐藏）：моё
   - 选项：моё / мое / моя
   - 答案／参考：моё
   - 解析：这里读моё，练习要求保留Ё。

9. 【input】输入“菜单”的俄语。
   - 答案／参考：меню
   - 解析：меню以Ю结尾。

10. 【input】输入本课学到的“我的”：мо…
   - 答案／参考：моё
   - 解析：本题要求моё，保留Ё。

11. 【input】听后输入这个词。
   - 朗读内容（听力先隐藏）：ещё
   - 答案／参考：ещё
   - 解析：ещё中的Щ和Ё都不能漏。

12. 【order】排列“请再说一遍”。
   - 答案／参考：Ещё раз, пожалуйста.
   - 解析：Ещё раз是再一次。

13. 【choice】Е、Ё、Ю、Я接在辅音后时，通常还提示什么？
   - 选项：前面的辅音软化 / 每次都停顿 / 前面的辅音一定清化
   - 答案／参考：前面的辅音软化
   - 解析：这是一条常见规律；Ж、Ш、Ц等要随词学习。

14. 【oral】你看不懂菜单：先请求菜单，再请求对方重复。
   - 答案／参考：Ме́ню, пожа́луйста.；Ещё раз, пожа́луйста.
   - 解析：说完再对照参考；名字可以换成自己的。

## 第10课：最后五个字母与出入口

认识全部33个字母；能区分入口、出口和酒店。

### 学习卡片

фо́то — вход — вы́ход — центр — оте́ль；подъе́зд中的Ъ起分隔作用。

- вход：入口。词尾Д清化，近似[t]，拼写保留Д。
- вы́ход：出口。重音已标出；听后跟读，再回忆中文。
- центр：中心。重音已标出；听后跟读，再回忆中文。
- оте́ль：酒店。重音已标出；听后跟读，再回忆中文。
- подъе́зд：楼门／单元入口。观察Ъ的分隔作用，暂不要求主动使用。

- Где вход?：入口在哪里？
- Где оте́ль?：酒店在哪里？

- Ь、Ъ本身不独立发音。
- Ь有提示软化、分隔和语法等作用，不是所有位置都只解释为软化。
- 把вход和выход连同标识一起记，注意多出的вы。

### 练习与答案

1. 【match】配对最后5个字母的大小写。
   - 答案／参考：Ф ↔ ф；Х ↔ х；Ц ↔ ц；Ь ↔ ь；Ъ ↔ ъ
   - 解析：逐项对应后再读一遍。

2. 【choice】哪些字母本身不独立发音？
   - 选项：Ь、Ъ / Ф、Х / Ц、Ф
   - 答案／参考：Ь、Ъ
   - 解析：软音符号和硬音符号没有独立音值。

3. 【choice】哪个词表示出口？
   - 选项：вход / выход / отель
   - 答案／参考：выход
   - 解析：выход是出口，вход是入口。

4. 【choice】哪个词表示酒店？
   - 选项：центр / отель / чай
   - 答案／参考：отель
   - 解析：отель是酒店。

5. 【choice】Ц通常属于哪类辅音？
   - 选项：成对浊辅音 / 不成对清辅音 / 元音
   - 答案／参考：不成对清辅音
   - 解析：Ц通常为硬的清塞擦音。

6. 【listen】听后选择意思。
   - 朗读内容（听力先隐藏）：Где вход?
   - 选项：入口在哪里 / 出口在哪里 / 菜单在哪里
   - 答案／参考：入口在哪里
   - 解析：вход表示入口。

7. 【listen】听到的是什么标识？
   - 朗读内容（听力先隐藏）：вы́ход
   - 选项：入口 / 出口 / 中心
   - 答案／参考：出口
   - 解析：重音在вы́。

8. 【listen】对方在找什么？
   - 朗读内容（听力先隐藏）：Где оте́ль?
   - 选项：银行 / 酒店 / 茶
   - 答案／参考：酒店
   - 解析：Где отель?表示酒店在哪里。

9. 【input】输入“入口”的俄语。
   - 答案／参考：вход
   - 解析：末尾写Д，不因清化写成Т。

10. 【input】输入“出口”的俄语。
   - 答案／参考：выход
   - 解析：比вход多出ы，整体是вы-ход。

11. 【input】输入“酒店”的俄语。
   - 答案／参考：отель
   - 解析：词尾软音符号Ь要保留。

12. 【order】排列“酒店在哪里”。
   - 答案／参考：Где отель?
   - 解析：Где加地点词可以询问位置。

13. 【choice】读到подъезд中的Ъ，应当怎样处理？
   - 选项：把Ъ读成一个元音 / 让后面的Е与前辅音分开读 / 把后面的Е删掉
   - 答案／参考：让后面的Е与前辅音分开读
   - 解析：Ъ在这个词里起分隔作用。

14. 【oral】你要进入酒店，分别询问酒店和入口在哪里。
   - 答案／参考：Где оте́ль?；Где вход?
   - 解析：说完再对照参考；名字可以换成自己的。

## 第11课：重音与非重读元音

能找到常见词重音；理解非重读О的常见弱化。

### 学习卡片

во-ДА́；мо-ло-КО́；хо-ро-ШО́；ПЛО́-хо；спа-СИ́-бо。大写只是这里标示重读音节的方法。

- вода́：水。重音在第二音节；前面的О弱化。
- молоко́：牛奶。重音在最后一音节。
- хорошо́：好／好的。重音已标出；听后跟读，再回忆中文。
- пло́хо：不好／糟糕。重音已标出；听后跟读，再回忆中文。
- спаси́бо：谢谢。重音已标出；听后跟读，再回忆中文。

- Вода́, пожа́луйста.：请给我水。
- Хорошо́, спаси́бо.：好的，谢谢。

- 重音符号帮助学习，普通俄语书写通常不标；输入题可以省略。
- 非重读О常弱化为接近[ɐ]或[ə]的音，具体随位置变化。
- 不要因为听起来接近А，就把水вода写成вада。

### 练习与答案

1. 【choice】вода́的重音在哪一音节？
   - 选项：第一音节 / 第二音节 / 没有重音
   - 答案／参考：第二音节
   - 解析：вода́重读да。

2. 【choice】молоко́重读哪个元音？
   - 选项：第一个О / 第二个О / 最后一个О
   - 答案／参考：最后一个О
   - 解析：молоко́重读最后一个音节。

3. 【choice】пло́хо重音在哪一音节？
   - 选项：第一音节 / 第二音节 / 都重读
   - 答案／参考：第一音节
   - 解析：пло́хо的пло重读。

4. 【choice】非重读О的常见情况是？
   - 选项：永远读清楚的[o] / 发生弱化 / 不需要发任何声音
   - 答案／参考：发生弱化
   - 解析：弱化不是省略，也不等于改变拼写。

5. 【choice】听起来接近вада的“水”，应怎样拼写？
   - 选项：вада / вода / водо
   - 答案／参考：вода
   - 解析：标准拼写为вода。

6. 【listen】对方想要什么？
   - 朗读内容（听力先隐藏）：Вода́, пожа́луйста.
   - 选项：水 / 牛奶 / 茶
   - 答案／参考：水
   - 解析：вода是水。

7. 【listen】听后选择重音正确的写法。
   - 朗读内容（听力先隐藏）：молоко́
   - 选项：мо́локо / моло́ко / молоко́
   - 答案／参考：молоко́
   - 解析：最后一个О重读。

8. 【listen】这句话在表达什么？
   - 朗读内容（听力先隐藏）：Хорошо́, спаси́бо.
   - 选项：听不懂 / 好的，谢谢 / 请结账
   - 答案／参考：好的，谢谢
   - 解析：хорошо在这里表示好的。

9. 【input】输入“水”的俄语。
   - 答案／参考：вода
   - 解析：保留非重读О。

10. 【input】输入“牛奶”的俄语。
   - 答案／参考：молоко
   - 解析：两个非重读О也照原拼写保留。

11. 【input】听后输入这个词。
   - 朗读内容（听力先隐藏）：спаси́бо
   - 答案／参考：спасибо
   - 解析：重读И；输入时不要求标重音。

12. 【order】排列“好的，谢谢”。
   - 答案／参考：Хорошо, спасибо.
   - 解析：先回应хорошо，再表示感谢。

   - 选项：手机拼写错误 / 那是学习用重音标记 / 所有词都可随意删字

14. 【oral】先请求水，再回应“好的，谢谢”。注意重音。
   - 答案／参考：Вода́, пожа́луйста.；Хорошо́, спаси́бо.

## 第12课：辅音硬软与数字初识

能观察Ь和И等软化提示；能认出七、八。

### 学习卡片

先听：ма — мя；лук — люк。再读：день、семь、во́семь。此处只比较声音，不要求记新例词意思。

- день：一天／日。重音已标出；听后跟读，再回忆中文。
- де́ньги：钱。重音已标出；听后跟读，再回忆中文。
- семь：七。重音已标出；听后跟读，再回忆中文。
- во́семь：八。重音已标出；听后跟读，再回忆中文。
- до́брый день：您好／日安。重音已标出；听后跟读，再回忆中文。

- До́брый день!：您好！
- Повтори́те, пожа́луйста.：请重复。

- 许多辅音有硬软两种音值；软音时舌中部向硬腭抬起。
- Ь不是额外的元音；день末尾的Н是软音。
- Ж、Ш、Ц通常硬；Ч、Щ、Й通常软。

### 练习与答案

1. 【choice】день末尾的Ь是否单独读成元音？
   - 选项：是，读э / 不，它不独立发音 / 是，读ы
   - 答案／参考：不，它不独立发音
   - 解析：Ь在这里提示前面的Н软化。

2. 【choice】哪组字母通常表示硬辅音？
   - 选项：Ж、Ш、Ц / Ч、Щ、Й / Е、Ё、Ю
   - 答案／参考：Ж、Ш、Ц
   - 解析：Ж、Ш、Ц通常是硬音。

3. 【choice】哪组字母通常表示软辅音？
   - 选项：Б、П、М / Ч、Щ、Й / О、А、У
   - 答案／参考：Ч、Щ、Й
   - 解析：Ч、Щ、Й通常是软音。

4. 【choice】семь是多少？
