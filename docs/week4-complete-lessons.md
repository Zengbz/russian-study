## 第22课：我的、您的、谁的

**目标：** 用熟悉的旅行物品练习归属，按名词的性选择形式。

### 学习内容

мой биле́т — моя́ ка́рта — моё ме́сто；ваш телефо́н — ва́ша ви́за — ва́ше и́мя。биле́т重读第二音节。

- мой · моя́ · моё：我的。分别搭配阳性、阴性、中性单数名词；跟物品名词的性一致，不跟主人的性别变化。
- ваш · ва́ша · ва́ше：您的／你们的。这里优先练礼貌的“您的”，同样随被修饰名词的性变化。
- чей · чья · чьё：谁的。问阳性用чей，阴性用чья，中性用чьё；чья、чьё中的Ь要保留。
- докуме́нт：证件／文件。阳性名词。
- телефо́н：电话／手机。阳性名词。

- Э́то мой биле́т.：这是我的票。
- Э́то ва́ша ка́рта?：这是您的卡吗？
- Чей э́то телефо́н?：这是谁的手机？

- 本课只练单数、主格：мой билет；моя карта；моё место。
- 归属词的形式看物品名词，不看物品主人是男性还是女性。
- 介绍句型中的Это保持不变：Это моя карта，不改成Эта。
- чей／чья／чьё先做辨认；不要一次背全部格变化。

### 练习与答案

1. 【match】把物品归属短语与中文配对。
   - 配对内容：мой билет ↔ 我的票（阳性）；моя карта ↔ 我的卡（阴性）；моё место ↔ 我的座位（中性）；ваш телефон ↔ 您的手机（阳性）
   - 答案／参考：мой билет ↔ 我的票（阳性）；моя карта ↔ 我的卡（阴性）；моё место ↔ 我的座位（中性）；ваш телефон ↔ 您的手机（阳性）
   - 解析：先找物品名词，再检查前面的мой／моя／моё或ваш。

2. 【choice】“这是我的护照”：Это ___ паспорт. 应选哪个？
   - 选项：мой / моя / моё
   - 答案／参考：мой
   - 解析：паспорт是阳性单数，所以用мой。

3. 【choice】说话者是男性，怎样说“这是我的卡”？
   - 选项：Это мой карта. / Это моя карта. / Это моё карта.
   - 答案／参考：Это моя карта.
   - 解析：карта是阴性。说话者是男性也用моя。

4. 【choice】“这是我的座位”：Это ___ место. 应选哪个？
   - 选项：мой / моя / моё
   - 答案／参考：моё
   - 解析：место是中性单数，用моё；Ё要保留。

5. 【choice】礼貌问“这是您的卡吗”，选哪句？
   - 选项：Это ваш карта? / Это ваша карта? / Это ваше карта?
   - 答案／参考：Это ваша карта?
   - 解析：карта是阴性，与ваша搭配。

6. 【choice】问“这是谁的手机”，选哪句？
   - 选项：Кто это? / Чей это телефон? / Где телефон?
   - 答案／参考：Чей это телефон?
   - 解析：чей询问归属，телефон是阳性；Кто это?问的是这是谁。

7. 【listen】听后判断票属于谁。
   - 朗读内容（做题前隐藏）：Э́то мой биле́т.
   - 选项：说话者本人 / 听话者 / 没有说明
   - 答案／参考：说话者本人
   - 解析：мой билет表示我的票。

8. 【listen】对方在确认什么？
   - 朗读内容（做题前隐藏）：Э́то ва́ша ка́рта?
   - 选项：这是不是您的卡 / 您叫什么名字 / 这是谁的手机
   - 答案／参考：这是不是您的卡
   - 解析：ваша карта表示您的卡，疑问语调表示确认。

9. 【listen】对方主要想知道什么？
   - 朗读内容（做题前隐藏）：Чей э́то телефо́н?
   - 选项：手机在哪里 / 手机是谁的 / 手机多少钱
   - 答案／参考：手机是谁的
   - 解析：Чей…?在问物品归属。

10. 【input】只填空缺词：Это ___ карта.（这是我的卡。）
   - 答案／参考：моя
   - 解析：карта是阴性，填моя。

11. 【input】只填空缺词：___ это виза?（这是谁的签证？）
   - 答案／参考：чья
   - 解析：виза是阴性，问谁的用чья，保留Ь。

12. 【input】听后输入这组短语。
   - 朗读内容（做题前隐藏）：моё ме́сто
   - 答案／参考：моё место
   - 解析：место是中性，前面用моё。

13. 【order】用词块组成“这是我的票”。
   - 答案／参考：Это мой билет.
   - 解析：Это＋мой＋билет；介绍句中不用额外加系动词。

14. 【order】用词块组成“这是您的卡吗”。
   - 答案／参考：Это ваша карта?
   - 解析：ваша与阴性名词карта配合。

15. 【oral】指着自己的票和卡分别介绍，再问对方一件物品是不是他的。
   - 答案／参考：Э́то мой биле́т.；Э́то моя́ ка́рта.；Э́то ваш телефо́н?
   - 解析：先独立说，再对照参考；需要提示时如实记录。

   - 口语自检：票用мой билет；卡用моя карта；礼貌确认用ваш／ваша／ваше


## 第23课：描述大小和新旧

**目标：** 用形容词描述熟悉物品，初步练习与名词的性配合。

### 学习内容

но́вый — но́вая — но́вое；большо́й — больша́я — большо́е；ма́ленький — ма́ленькая — ма́ленькое。

- но́вый：新的。阳性новый；阴性новая；中性новое。
- ста́рый：旧的。这里描述物品的新旧；阴性старая，中性старое。
- большо́й：大的。阴性большая，中性большое，重音都在词尾部分。
- ма́ленький：小的。阴性маленькая，中性маленькое；重音保持在ма。
- хоро́ший：好的。阴性хорошая，中性хорошее；不要只换最后一个字母。
- кафе́：咖啡馆。复习词；不变格名词，中性，本课搭配маленькое кафе。

- Э́то но́вый па́спорт.：这是新护照。
- Э́то ма́ленькое кафе́.：这是小咖啡馆。
- Э́то моя́ но́вая ви́за.：这是我的新签证。

- 在本课名词短语里，形容词和名词的性一致。
- 先整组记：новый паспорт／новая виза／новое место，不机械地只改最后一个字母。
- кафе是中性：маленькое кафе。
- хорошо是前面学过的“好／好的”回应；修饰阳性名词时本课用хороший。

### 练习与答案

1. 【choice】“新护照”的正确搭配是？
   - 选项：новый паспорт / новая паспорт / новое паспорт
   - 答案／参考：новый паспорт
   - 解析：паспорт是阳性，搭配новый。

2. 【choice】“新签证”的正确搭配是？
   - 选项：новый виза / новая виза / новое виза
   - 答案／参考：новая виза
   - 解析：виза是阴性，搭配новая。

3. 【choice】“小咖啡馆”的正确搭配是？
   - 选项：маленький кафе / маленькая кафе / маленькое кафе
   - 答案／参考：маленькое кафе
   - 解析：кафе是中性不变格名词，搭配маленькое。

4. 【choice】“大的银行”应选哪组？
   - 选项：большой банк / большая банк / большое банк
   - 答案／参考：большой банк
   - 解析：банк是阳性，搭配большой。

5. 【choice】要说“好的酒店”，本课使用哪个搭配？
   - 选项：хорошо отель / хороший отель / хорошая отель
   - 答案／参考：хороший отель
   - 解析：отель是阳性名词，这里用形容词хороший。

6. 【match】把5个描述词与意思配对。
   - 配对内容：новый ↔ 新的，阳性形式；старый ↔ 旧的，阳性形式；большой ↔ 大的，阳性形式；маленький ↔ 小的，阳性形式；хороший ↔ 好的，阳性形式
   - 答案／参考：новый ↔ 新的，阳性形式；старый ↔ 旧的，阳性形式；большой ↔ 大的，阳性形式；маленький ↔ 小的，阳性形式；хороший ↔ 好的，阳性形式
   - 解析：这些是本课展示的阳性形式；放在名词前还要检查配合。

7. 【listen】听后选择对护照的描述。
   - 朗读内容（做题前隐藏）：Э́то но́вый па́спорт.
   - 选项：新的 / 旧的 / 小的
   - 答案／参考：新的
   - 解析：новый表示新的。

8. 【listen】听后选择咖啡馆的特征。
   - 朗读内容（做题前隐藏）：Э́то ма́ленькое кафе́.
   - 选项：大 / 小 / 旧
   - 答案／参考：小
   - 解析：маленькое修饰中性名词кафе。

9. 【listen】听后选择卡片的特征。
   - 朗读内容（做题前隐藏）：Э́то ста́рая ка́рта.
   - 选项：新 / 旧 / 大
   - 答案／参考：旧
   - 解析：старая是阴性形式，表示旧的。

10. 【input】只填空缺词：Это ___ паспорт.（这是新护照。）
   - 答案／参考：новый
   - 解析：阳性паспорт前用новый。

11. 【input】只填空缺词：Это ___ виза.（这是新签证，只填“新的”。）
   - 答案／参考：новая
   - 解析：виза是阴性，修饰它的“新的”用новая。

12. 【input】听后输入“旧的”的这个阳性形式。
   - 朗读内容（做题前隐藏）：ста́рый
   - 答案／参考：старый
   - 解析：старый中有Ы和Й。

13. 【order】用词块组成“这是小咖啡馆”。
   - 答案／参考：Это маленькое кафе.
   - 解析：кафе是中性，因此用маленькое。

14. 【order】用词块组成“这是我的新签证”。
   - 答案／参考：Это моя новая виза.
   - 解析：моя和новая都与阴性名词виза配合。

15. 【oral】分别描述新护照、小咖啡馆和自己的新签证。
   - 答案／参考：Э́то но́вый па́спорт.；Э́то ма́ленькое кафе́.；Э́то моя́ но́вая ви́за.
   - 解析：先独立说，再对照参考；需要提示时如实记录。

   - 口语自检：新护照用новый паспорт；小咖啡馆用маленькое кафе；新签证用новая виза


## 第24课：一个和多个

**目标：** 区分单复数，练4组常见变化并认识стул的特殊复数。

### 学习内容

ко́мната — ко́мнаты；су́мка — су́мки；магази́н — магази́ны；стол — столы́。复习биле́т — биле́ты。

- стол — столы́：桌子 — 多张桌子。复数重音移到词尾Ы。
- стул — сту́лья：椅子 — 多把椅子。这是特殊变化，本课作为整组辨认，不类推成стулы。
- ко́мната — ко́мнаты：房间 — 多个房间。阴性名词，复数以Ы结尾。
- су́мка — су́мки：包 — 多个包。К后这里写И，不写Ы。
- магази́н — магази́ны：商店 — 多家商店。复数以Ы结尾，重音仍在ЗИ。
- мои́ · ва́ши：我的（复数）· 您的／你们的（复数）。主格复数中不再按阳、阴、中性分别选择这组形式。

- Э́то су́мка.：这是一个包。
- Э́то су́мки.：这些是包。
- Э́то мои́ биле́ты.：这些是我的票。

- 复数形式不是统一加一个词尾，要连同重音一起记。
- 本课重点写столы、комнаты、сумки、магазины；стулья先辨认。
- 介绍多个东西仍可以用Это…：Это сумки，不需要在这个句型里改Это。
- 复数归属练мои сумки、ваши билеты；复数“新的”是новые，例如новые сумки。

### 练习与答案

1. 【match】把单数名词与它的复数配对。
   - 配对内容：стол ↔ столы；комната ↔ комнаты；сумка ↔ сумки；магазин ↔ магазины；стул ↔ стулья
   - 答案／参考：стол ↔ столы；комната ↔ комнаты；сумка ↔ сумки；магазин ↔ магазины；стул ↔ стулья
   - 解析：стул→стулья是特殊变化；其他几组也要连同拼写和重音记忆。

2. 【choice】哪个词形表示多个包？
   - 选项：сумка / сумки / сумкы
   - 答案／参考：сумки
   - 解析：сумки是本课使用的主格复数，К后写И。

3. 【choice】用本课Это…介绍多个包，哪句完整正确？
   - 选项：Это сумка. / Это сумки. / Это сумкы.
   - 答案／参考：Это сумки.
   - 解析：在这个介绍句型中，Это保持不变，名词用复数сумки。

4. 【choice】“这些是我的票”：Это ___ билеты. 应填？
   - 选项：мой / моя / мои
   - 答案／参考：мои
   - 解析：билеты是复数，前面用мои。

5. 【choice】стул的复数是？
   - 选项：стулы / стулья / стули
   - 答案／参考：стулья
   - 解析：стул→стулья作为特殊变化记住。

6. 【listen】听后判断物品数量。
   - 朗读内容（做题前隐藏）：Э́то су́мки.
   - 选项：一个包 / 不止一个包 / 没有包
   - 答案／参考：不止一个包
   - 解析：сумки在本句中是复数。

7. 【listen】听后选择对应意思。
   - 朗读内容（做题前隐藏）：столы́
   - 选项：一张桌子 / 多张桌子 / 多把椅子
   - 答案／参考：多张桌子
   - 解析：столы是стол的复数，重音在Ы。

8. 【listen】对方在确认什么？
   - 朗读内容（做题前隐藏）：Э́то ва́ши биле́ты?
   - 选项：这是不是您的单张票 / 这些是不是您的票 / 这些是不是我的票
   - 答案／参考：这些是不是您的票
   - 解析：ваши与复数билеты搭配，句子在确认归属。

9. 【input】把“房间”комната改为本课的主格复数。
   - 答案／参考：комнаты
   - 解析：комната→комнаты，末尾А变Ы。

10. 【input】把“包”сумка改为本课的主格复数。
   - 答案／参考：сумки
   - 解析：сумка→сумки，К后写И。

11. 【input】把“商店”магазин改为本课的主格复数。
   - 答案／参考：магазины
   - 解析：магазин→магазины。

12. 【input】听后输入这个复数名词。
   - 朗读内容（做题前隐藏）：столы́
   - 答案／参考：столы
   - 解析：столы重读最后的Ы；输入时可以不标重音。

13. 【order】用词块组成“这些是我的包”。
   - 答案／参考：Это мои сумки.
   - 解析：复数сумки前用мои。

14. 【order】用词块组成“这些是新包”。
   - 答案／参考：Это новые сумки.
