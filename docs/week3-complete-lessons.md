# 第3周：介绍自己与认识旅伴

人称、名词的性、来源、职业与否定；持续拼写和听写

## 第15课：这是谁、这是什么

区分问人和问物，并用Это…回答。

### 学习卡片

кто — что — э́то；челове́к重读最后一音节；вещь末尾保留Ь。

- кто：谁。重音已标出；听后跟读，再回忆中文。
- что：什么。常见读音接近што。
- э́то：这／这是。重音已标出；听后跟读，再回忆中文。
- челове́к：人。重音已标出；听后跟读，再回忆中文。
- ве́щь：东西。重音已标出；听后跟读，再回忆中文。

- Кто э́то?：这是谁？
- Что э́то?：这是什么？
- Э́то А́нна.：这是安娜。

- 问人常用Кто，问物常用Что。
- 现在时介绍身份时，Это与名词间通常不加“是”的动词。
- 这是Э́то А́нна；“我叫安娜”则是Меня́ зову́т А́нна。

### 练习与答案

1. 【choice】想问“这是谁”，选哪句？
   - 选项：Кто это? / Что это? / Где это?
   - 答案／参考：Кто это?
   - 解析：Кто用于问人。

2. 【choice】指着一件东西，想问“这是什么”，选哪句？
   - 选项：Как вас зовут? / Что это? / Кто это?
   - 答案／参考：Что это?
   - 解析：Что用于问事物。

3. 【choice】“这是安娜”应如何说？
   - 选项：Это Анна. / Я Анна. / Где Анна?
   - 答案／参考：Это Анна.
   - 解析：Это用于指认、介绍。

4. 【choice】哪个词表示人？
   - 选项：человек / вещь / счёт
   - 答案／参考：человек
   - 解析：человек表示人。

5. 【match】把左边内容与右边对应项配对。
   - 答案／参考：кто ↔ 谁；что ↔ 什么；это ↔ 这／这是；вещь ↔ 东西
   - 解析：逐项对应后再读一遍。

6. 【listen】听到的问句在问什么？
   - 朗读内容（听力先隐藏）：Кто э́то?
   - 选项：这是谁 / 这是什么 / 地铁在哪里
   - 答案／参考：这是谁
   - 解析：Кто问人。

7. 【listen】听到的问句在问什么？
   - 朗读内容（听力先隐藏）：Что э́то?
   - 选项：这是什么 / 您叫什么 / 您来自哪里
   - 答案／参考：这是什么
   - 解析：Что通常读音接近што。

8. 【listen】听到的是哪一种介绍？
   - 朗读内容（听力先隐藏）：Э́то А́нна.
   - 选项：我是安娜 / 这是安娜 / 安娜在哪里
   - 答案／参考：这是安娜
   - 解析：Это Анна是在介绍另一个人。

9. 【input】把“谁”写成俄语。
   - 答案／参考：кто
   - 解析：注意к-т-о的顺序。

10. 【input】输入“这是什么？”的俄语。
   - 答案／参考：Что это?
   - 解析：Что问事物，это指这个。

11. 【input】听后输入这个词。
   - 朗读内容（听力先隐藏）：вещь
   - 答案／参考：вещь
   - 解析：末尾是Щ和Ь。

12. 【order】排列“这是安娜”。
   - 答案／参考：Это Анна.
   - 解析：现在时通常不加系动词。

13. 【choice】给Это Анна.额外加一个英语is，符合本课俄语句型吗？
   - 选项：符合 / 不符合
   - 答案／参考：不符合
   - 解析：本课句型直接用Это＋姓名。

14. 【oral】指着安娜问“这是谁”，再自己回答；指着物品问“这是什么”。
   - 答案／参考：Кто э́то? Э́то А́нна.；Что э́то?
   - 解析：说完再对照参考；名字可以换成自己的。

## 第16课：人称代词与指代

辨认8个人称代词，重点练礼貌称呼与介绍他人。

### 学习卡片

он — она́ — оно́ — они́，注意词尾和重音；ты与вы中的Ы都不要写成И。

- я：我。重音已标出；听后跟读，再回忆中文。
- ты：你。重音已标出；听后跟读，再回忆中文。
- он：他。重音已标出；听后跟读，再回忆中文。
- она́：她。重音已标出；听后跟读，再回忆中文。
- оно́：它，中性单数指代。重音已标出；听后跟读，再回忆中文。
- мы：我们。重音已标出；听后跟读，再回忆中文。
- вы：您／你们。重音已标出；听后跟读，再回忆中文。
- они́：他们／她们／它们。重音已标出；听后跟读，再回忆中文。

- Он Ива́н.：他是伊万。
- Она́ А́нна.：她是安娜。
- А вы?：您呢？

- 面对陌生成年人，优先使用礼貌вы。
- оно常指代中性单数名词；不能把所有中文“它”都机械换成оно。
- 俄语代词指代名词时也涉及语法性，后面继续学习。

### 练习与答案

1. 【match】把左边内容与右边对应项配对。
   - 答案／参考：я ↔ 我；ты ↔ 你；мы ↔ 我们；вы ↔ 您／你们
   - 解析：逐项对应后再读一遍。

2. 【match】把左边内容与右边对应项配对。
   - 答案／参考：он ↔ 他；она ↔ 她；оно ↔ 它，中性单数；они ↔ 他们／她们／它们
   - 解析：逐项对应后再读一遍。

3. 【choice】礼貌询问陌生成年人姓名，选哪个代词形式？
   - 选项：ты / вы / он
   - 答案／参考：вы
   - 解析：礼貌称呼优先用вы。

4. 【choice】介绍女性安娜，应选哪句？
   - 选项：Он Анна. / Она Анна. / Мы Анна.
   - 答案／参考：Она Анна.
   - 解析：女性人称用она。

5. 【choice】介绍男性伊万，应选哪句？
   - 选项：Он Иван. / Она Иван. / Оно Иван.
   - 答案／参考：Он Иван.
   - 解析：男性人称用он。

6. 【listen】听后判断是谁。
   - 朗读内容（听力先隐藏）：Она́ А́нна.
   - 选项：她是安娜 / 他是伊万 / 我们是游客
   - 答案／参考：她是安娜
   - 解析：она是她。

7. 【listen】按听到的顺序选择。
   - 朗读内容（听力先隐藏）：Мы. Вы.
   - 选项：我→你 / 我们→您／你们 / 他→她
   - 答案／参考：我们→您／你们
   - 解析：мы和вы都使用Ы。

8. 【listen】听后选对应意思。
   - 朗读内容（听力先隐藏）：они́
   - 选项：他 / 她 / 他们／她们／它们
   - 答案／参考：他们／她们／它们
   - 解析：они是复数指代。

9. 【input】输入“她”的俄语。
   - 答案／参考：она
   - 解析：она以А结尾。

10. 【input】输入“我们”的俄语。
   - 答案／参考：мы
   - 解析：мы用Ы，不是И。

11. 【input】听后输入这个代词。
   - 朗读内容（听力先隐藏）：они́
   - 答案／参考：они
   - 解析：они最后是И。

12. 【order】排列“他是伊万”。
   - 答案／参考：Он Иван.
   - 解析：人称代词后直接接姓名。

13. 【order】排列“她是安娜”。
   - 答案／参考：Она Анна.
   - 解析：女性用она。

14. 【oral】分别介绍伊万和安娜，然后礼貌问对方姓名。
   - 答案／参考：Он Ива́н. Она́ А́нна.；Как вас зову́т?
   - 解析：说完再对照参考；名字可以换成自己的。

## 第17课：旅行名词的性

认识常见词尾，并能辨认6个旅行名词。

### 学习卡片

па́спорт — биле́т；ка́рта — ви́за；ме́сто — и́мя。先读重音，再观察词尾。

- па́спорт：护照。阳性，辅音结尾。
- биле́т：票。阳性，辅音结尾。
- ка́рта：卡／地图。阴性，А结尾。
- ви́за：签证。阴性，А结尾。
- ме́сто：地方／座位。中性，О结尾。
- и́мя：名字。中性特殊词，需要随词记住。
- оте́ль：酒店。阳性；Ь结尾的词不能只凭词尾判断性。

- Э́то па́спорт.：这是护照。
- Э́то ви́за.：这是签证。

- 常见情况下：辅音结尾多为阳性，А／Я结尾多为阴性，О／Е结尾多为中性。
- 规则有例外；имя是中性，Ь结尾的词要连同性一起记。
- 词尾清化是读音现象，不改变паспорт、билет等拼写。

### 练习与答案

1. 【choice】паспорт通常属于哪一种性？
   - 选项：阳性 / 阴性 / 中性
   - 答案／参考：阳性
   - 解析：паспорт是阳性名词。

2. 【choice】карта属于哪一种性？
   - 选项：阳性 / 阴性 / 中性
   - 答案／参考：阴性
   - 解析：карта是阴性名词。

3. 【choice】место属于哪一种性？
   - 选项：阳性 / 阴性 / 中性
   - 答案／参考：中性
   - 解析：место是中性名词。

4. 【choice】имя属于哪一种性？
   - 选项：阳性 / 阴性 / 中性
   - 答案／参考：中性
   - 解析：имя是中性特殊词，不能机械按Я结尾归类。

5. 【choice】看到Ь结尾，能保证这个词一定是阴性吗？
   - 选项：能，一定阴性 / 不能，需要随词记忆
   - 答案／参考：不能，需要随词记忆
   - 解析：例如отель是阳性，вещь是阴性。

6. 【match】把左边内容与右边对应项配对。
   - 答案／参考：паспорт ↔ 护照；билет ↔ 票；карта ↔ 卡／地图；виза ↔ 签证；место ↔ 地方／座位；имя ↔ 名字
   - 解析：逐项对应后再读一遍。

7. 【listen】对方指的是什么？
   - 朗读内容（听力先隐藏）：Э́то па́спорт.
   - 选项：签证 / 护照 / 地图
   - 答案／参考：护照
   - 解析：паспорт是护照。

8. 【listen】对方指的是什么？
   - 朗读内容（听力先隐藏）：Э́то ви́за.
   - 选项：票 / 名字 / 签证
   - 答案／参考：签证
   - 解析：виза是签证。

9. 【listen】听后选词义。
   - 朗读内容（听力先隐藏）：ме́сто
   - 选项：地方／座位 / 护照 / 酒店
   - 答案／参考：地方／座位
   - 解析：место是中性名词。

10. 【input】输入“护照”的俄语。
   - 答案／参考：паспорт
   - 解析：注意па-с-порт的拼写。

11. 【input】输入“签证”的俄语。
   - 答案／参考：виза
   - 解析：виза以А结尾。

12. 【input】听后输入这个词。
   - 朗读内容（听力先隐藏）：биле́т
   - 答案／参考：билет
   - 解析：重音在第二音节，拼写为билет。

13. 【order】排列“这是护照”。
   - 答案／参考：Это паспорт.
   - 解析：Это后接名词原形。

14. 【oral】分别指认护照、票、签证，使用Это…。
   - 答案／参考：Э́то па́спорт. Э́то биле́т. Э́то ви́за.

## 第18课：我来自哪里

能说来自中国，并听懂中亚几个国家名。

### 学习卡片

Кита́й — из Кита́я；Казахста́н — из Казахста́на。重音位置保持在对应词干音节。

- Кита́й：中国。重音已标出；听后跟读，再回忆中文。
- Казахста́н：哈萨克斯坦。重音已标出；听后跟读，再回忆中文。
- Кыргызста́н：吉尔吉斯斯坦。重音已标出；听后跟读，再回忆中文。
- Узбекиста́н：乌兹别克斯坦。重音已标出；听后跟读，再回忆中文。
- тури́ст：游客。重音已标出；听后跟读，再回忆中文。
- из：来自。后面的国家名会变形，这节先记整句。

- Я из Кита́я.：我来自中国。
- Вы из Казахста́на?：您来自哈萨克斯坦吗？
- Я тури́ст.：我是游客。

- 国家原形Китай，但“来自中国”用из Китая。
- из后面的属格变化后面正式学习，当前先记固定来源表达。
- Кыргызстан在这里采用该国正式俄语国名写法。

### 练习与答案

1. 【match】把左边内容与右边对应项配对。
   - 答案／参考：Китай ↔ 中国；Казахстан ↔ 哈萨克斯坦；Кыргызстан ↔ 吉尔吉斯斯坦；Узбекистан ↔ 乌兹别克斯坦
   - 解析：逐项对应后再读一遍。

2. 【choice】“我来自中国”应选哪句？
   - 选项：Я из Китай. / Я из Китая. / Я Китай.
   - 答案／参考：Я из Китая.
   - 解析：из后用Китая，本课先记整句。

3. 【choice】哪个词表示游客？
   - 选项：турист / паспорт / программист
   - 答案／参考：турист
   - 解析：турист是游客。

4. 【choice】“来自哈萨克斯坦”本课采用哪个形式？
   - 选项：из Казахстан / из Казахстана / из Китай
   - 答案／参考：из Казахстана
   - 解析：来源表达中用Казахстана。

5. 【choice】看到Китай和Китая，应该怎样理解？
   - 选项：两个不同国家 / 同一国家名在不同结构中的形式 / 其中一个一定拼错
   - 答案／参考：同一国家名在不同结构中的形式
   - 解析：不同语法结构会使词尾变化。

6. 【listen】对方来自哪里？
   - 朗读内容（听力先隐藏）：Я из Кита́я.
   - 选项：中国 / 哈萨克斯坦 / 乌兹别克斯坦
   - 答案／参考：中国
   - 解析：из Китая表示来自中国。

7. 【listen】这句话是在问什么？
   - 朗读内容（听力先隐藏）：Вы из Казахста́на?
   - 选项：您是游客吗 / 您来自哈萨克斯坦吗 / 您叫什么名字
   - 答案／参考：您来自哈萨克斯坦吗
   - 解析：Вы из Казахстана?是来源问句。

8. 【listen】对方的身份是？
   - 朗读内容（听力先隐藏）：Я тури́ст.
   - 选项：学生 / 游客 / 程序员
   - 答案／参考：游客
   - 解析：турист是游客。

9. 【input】输入“我来自中国”。
   - 答案／参考：Я из Китая.
   - 解析：不要把из后面的Китая写回原形Китай。

10. 【input】输入“游客”的俄语。
   - 答案／参考：турист
   - 解析：重音在И，普通输入可以不标重音。

11. 【input】听后输入这个国家名。
   - 朗读内容（听力先隐藏）：Кита́й
   - 答案／参考：Китай
   - 解析：原形Китай以Й结尾。

12. 【order】排列“我来自中国”。
   - 答案／参考：Я из Китая.
   - 解析：Я＋из＋Китая。

13. 【order】排列“您来自哈萨克斯坦吗”。
   - 答案／参考：Вы из Казахстана?
   - 解析：这里用问号和疑问语调表达询问。

14. 【oral】说出自己的姓名、来自中国和游客身份。
   - 答案／参考：Меня́ зову́т …；Я из Кита́я. Я тури́ст.
   - 解析：说完再对照参考；名字可以换成自己的。

## 第19课：职业、否定和也

能介绍程序员身份，并表达“不是”和“也是”。

### 学习卡片

про-грам-МИ́СТ；сту-ДЕ́НТ；ТО́-же。программист里的两个М都保留。

- программи́ст：程序员。注意双写мм。
- студе́нт：学生。重音已标出；听后跟读，再回忆中文。
- тури́ст：游客。重音已标出；听后跟读，再回忆中文。
- не：不。重音已标出；听后跟读，再回忆中文。
- то́же：也。重音已标出；听后跟读，再回忆中文。
- а：而／那么。А вы?在对话中可表示您呢？

- Я программи́ст.：我是程序员。
- Я не студе́нт.：我不是学生。
- Я то́же тури́ст.：我也是游客。

- 否定身份时通常把не放在身份名词前。
- не和后面的职业词在这里分开写。
- 本课使用程序员这一职业练习，女性也可以使用программист；更多职业形式以后展开。

### 练习与答案

1. 【choice】哪个词表示程序员？
   - 选项：программист / студент / турист
   - 答案／参考：программист
   - 解析：программист是程序员。

2. 【choice】“我不是学生”应选哪句？
   - 选项：Я студент. / Я не студент. / Я тоже студент.
