# 第1周：先学会开口

20个字母、问候、姓名与沟通补救

## 第1课：第一声你好

认出4个字母，开口说一句问候和一句告别。

### 学习卡片

ма、та、ма́ма、том：这些只用今天的4个字母。先练拼读，不要求另外背词义。

- Приве́т!：你好；用于较随意的问候。见面时用。
- Пока́!：再见；较随意。离开时用。
- да：是／对。回答肯定。
- нет：不／没有。回答否定；具体用法以后再展开。

- Приве́т!：你好！
- Пока́!：再见！

- 字母和实用短句分两条线学：字母练认读，长句先跟着声音整句学。
- 大写А与小写а是同一个字母。点击“字母名”听名称；拼读时看旁边的音值，不要把эм读进每一个音节。
- Приве́т和Пока́偏随意，适合和同龄旅伴打招呼。本周不要求读出这些短句里所有尚未专项学过的字母。
- 词上方的小斜线表示重音。单音节词一般不用另标；今天只跟读，重音规则后面再细练。

### 练习与答案

1. 【choice】找出俄语小写а对应的大写字母。
   - 选项：А / О / М / Т
   - 答案／参考：А
   - 解析：А和а是同一个字母。

2. 【choice】找出俄语大写М对应的小写字母。
   - 选项：т / о / м / а
   - 答案／参考：м
   - 解析：М的小写是м，不是拉丁字母n。

3. 【choice】拼读音节：м＋а，应该组成哪一项？
   - 选项：ма / ам / та / ом
   - 答案／参考：ма
   - 解析：先读辅音[m]，再接元音[a]，组成ма。

4. 【choice】刚见面时，你应该说哪一句？
   - 选项：Приве́т! / Пока́! / нет
   - 答案／参考：Приве́т!
   - 解析：Привет用于问候，Пока用于告别。

5. 【match】把大写字母与对应的小写字母配成对。
   - 答案／参考：А ↔ а；О ↔ о；М ↔ м；Т ↔ т
   - 解析：逐个认清字形。大小写表示同一个字母；不要按拉丁字母的读法猜。

6. 【listen】先听俄语，再选择对应的意思或字母。
   - 朗读内容（听力先隐藏）：эм
   - 选项：М / Т / А / О
   - 答案／参考：М
   - 解析：听到的是字母名称эм，对应М。

7. 【choice】Приве́т!在本课中的意思是？
   - 选项：你好 / 再见 / 不／没有
   - 答案／参考：你好
   - 解析：它是较随意的问候。

8. 【choice】Пока́!在本课中的意思是？
   - 选项：谢谢 / 再见 / 你好
   - 答案／参考：再见
   - 解析：离开时可以说Пока。

9. 【order】按“先见面、后告别”的顺序排列。
   - 答案／参考：Приве́т! Пока́!
   - 解析：见面问候在前，离开告别在后。

10. 【choice】用一个词作肯定回答，应选择？
   - 选项：да / нет
   - 答案／参考：да
   - 解析：да表示是／对，нет表示不／没有。

11. 【choice】你要表达“不／没有”，应该说？
   - 选项：да / нет
   - 答案／参考：нет
   - 解析：нет是本课的否定表达。

12. 【choice】哪一项的字母顺序是先т、再о、最后м？
   - 选项：мот / том / мат
   - 答案／参考：том
   - 解析：从左往右拼读；不要只凭外形相似猜。

13. 【listen】先听俄语，再选择对应的意思或字母。
   - 朗读内容（听力先隐藏）：Привет!
   - 选项：你好 / 再见 / 不／没有
   - 答案／参考：你好
   - 解析：听到Привет，是问候。

14. 【listen】先听俄语，再选择对应的意思或字母。
   - 朗读内容（听力先隐藏）：Пока!
   - 选项：是／对 / 你好 / 再见
   - 答案／参考：再见
   - 解析：听到Пока，是告别。

15. 【oral】先读А О М Т，再想象见到一位同龄旅伴：问候一下，最后告别。
   - 答案／参考：字母名称：а、о、эм、тэ。；见面：Приве́т!；离开：Пока́!
   - 解析：这是口头自检。说出来后再核对，应用不会自动判断你的发音是否正确。

## 第2课：把礼貌带上

认出4个新字母，能在三种情境中选择礼貌用语。

### 学习卡片

кот、нос、нет：只用已经学过的字母。听完后再尝试逐个拼读。

- Спаси́бо!：谢谢。收到帮助后说。
- Пожа́луйста.：请／不客气。含义取决于情境。
- Извини́те.：劳驾／对不起。打扰别人或表示歉意。
- Хорошо́.：好的。表示理解或接受。

- Спаси́бо!：谢谢！
- Извини́те, пожа́луйста.：劳驾／对不起。

- С看起来像拉丁C，却读[s]；Н看起来像拉丁H，却读[n]。外形熟悉时更要听声音。
- Е有位置相关的读法。今天先认识字母名称，再跟读нет，不把所有发音规则塞在一课。
- Пожалуйста可以表示“请”，也可以在别人道谢后表示“不客气”。要结合情境判断。
- Извините既能用于表示歉意，也能用来礼貌地引起陌生人的注意。

### 练习与答案

1. 【choice】昨天学过：离开时使用哪句？
   - 选项：Пока́! / Приве́т! / да
   - 答案／参考：Пока́!
   - 解析：告别时用Пока。

2. 【choice】昨天学过：哪个词是肯定回答？
   - 选项：нет / да
   - 答案／参考：да
   - 解析：да是肯定回答。

3. 【choice】小写т对应哪个大写字母？
   - 选项：М / Т / О / А
   - 答案／参考：Т
   - 解析：т和Т是同一个字母。

4. 【choice】先读м、再接а，组成？
   - 选项：ам / ма / та
   - 答案／参考：ма
   - 解析：顺序是м＋а。

5. 【match】把大写字母与对应的小写字母配成对。
   - 答案／参考：К ↔ к；С ↔ с；Е ↔ е；Н ↔ н
   - 解析：逐个认清字形。大小写表示同一个字母；不要按拉丁字母的读法猜。

6. 【listen】先听俄语，再选择对应的意思或字母。
   - 朗读内容（听力先隐藏）：эн
   - 选项：Н / С / К / Е
   - 答案／参考：Н
   - 解析：эн是俄语字母Н的名称。

7. 【choice】别人帮你拿到了东西，你想道谢。
   - 选项：Спаси́бо! / Пока́! / нет
   - 答案／参考：Спаси́бо!
   - 解析：收到帮助后说Спасибо。

8. 【choice】你接受了对方的安排，想说“好的”。
   - 选项：Хорошо́. / Приве́т! / Извини́те.
   - 答案／参考：Хорошо́.
   - 解析：Хорошо在这里表示好的。

9. 【order】把“劳驾／对不起”这句礼貌表达排好。
   - 答案／参考：Извини́те, пожа́луйста.
   - 解析：Извините提出礼貌打扰或歉意，пожалуйста让语气更客气。

10. 【choice】有人对你说Спасибо，你想回应“不客气”。
   - 选项：Пожа́луйста. / Пока́! / нет
   - 答案／参考：Пожа́луйста.
   - 解析：Пожалуйста在这里是不客气，而不是请。

11. 【choice】哪一个是已经学过的俄语单词нет？
   - 选项：тен / нет / кот
   - 答案／参考：нет
   - 解析：注意н-е-т的顺序。

12. 【choice】Н的常见音值是哪一个？
   - 选项：[n] / [m] / [s]
   - 答案／参考：[n]
   - 解析：俄语Н读[n]，不能按拉丁H猜。

13. 【listen】先听俄语，再选择对应的意思或字母。
   - 朗读内容（听力先隐藏）：Спасибо!
   - 选项：谢谢 / 你好 / 再见
   - 答案／参考：谢谢
   - 解析：听到Спасибо，是道谢。

14. 【listen】先听俄语，再选择对应的意思或字母。
   - 朗读内容（听力先隐藏）：Извините, пожалуйста.
   - 选项：劳驾／对不起 / 好的 / 不／没有
   - 答案／参考：劳驾／对不起
   - 解析：这是一句礼貌打扰或道歉用语。

15. 【oral】读К С Е Н，然后演练：先礼貌地打扰别人，得到帮助后道谢。
   - 答案／参考：字母名称：ка、эс、е、эн。；Извини́те, пожа́луйста.；Спаси́бо!
   - 解析：这是口头自检。说出来后再核对，应用不会自动判断你的发音是否正确。

## 第3课：说出你的名字

认出4个新字母，完成姓名问答。

### 学习卡片

рот、вот、рука́：只用已经学过的字母。先听再拼读。

- я：我。先整词认识，Я的字母专项在第9天。
- вы：您／你们。和陌生人交流时常用礼貌вы。
- Меня́ зову́т …：我叫……。整句学，不在今天分析变格。
- Как вас зову́т?：您叫什么名字？。先听懂，再尝试问出来。

- Меня́ зову́т …：我叫……
- Как вас зову́т?：您叫什么名字？

- Р与拉丁P外形相似，但不是[p]；В与拉丁B外形相似，但不是[b]。今天把这两组分清。
- Р是舌尖音。先听短促的声音并模仿，不会连续弹舌也可以继续学句子。
- Меня зовут…整体表示“我叫……”，今天不拆解格变化。名字可以先用自己习惯的读法。
- 和陌生人礼貌交流时用вы。Как вас зовут?中的形式先按整句记忆。

   - 答案／参考：н
   - 解析：Н与н是同一字母。

4. 【choice】哪一个是问候，而不是告别？

   - 答案／参考：Приве́т!

5. 【match】把大写字母与对应的小写字母配成对。
   - 答案／参考：Р ↔ р；В ↔ в；У ↔ у；Б ↔ б
   - 解析：逐个认清字形。大小写表示同一个字母；不要按拉丁字母的读法猜。

   - 选项：В / Б / Р / У
   - 答案／参考：В
   - 解析：вэ是В的名称；Б的名称是бэ。

7. 【choice】я的意思是？
   - 选项：我 / 您／你们 / 不
   - 答案／参考：我
   - 解析：я表示我；字母Я会在第9天专项学习。

8. 【choice】和陌生人礼貌交流时，应该先学会哪一个称呼？

   - 答案／参考：вы
   - 解析：вы可以表示礼貌的您，也可表示你们。

9. 【order】把“我叫……”的固定开头排好。

   - 解析：固定开头是Меня зовут，后面接自己的名字。

## 第4课：听不懂也能继续聊

认出4个新字母，主动说出两句沟通补救语。

### 学习卡片

дом、ми́р、па́па：只用已经学过的字母。读完后再对照声音。

- Я не понима́ю.：我听不懂／不明白。听不懂时可以直接说明。
- Повтори́те.：请重复。可以加пожалуйста使请求更礼貌。
- Ме́дленно, пожа́луйста.：请慢一点。对方说得太快时用。
- Ещё раз.：再一次。本周先当声音语块。

- Я не понима́ю.：我听不懂／不明白。
- Повтори́те, пожа́луйста.：请再说一遍。

- 遇到听不懂的回答时，先说明“我不明白”，再提出“请重复”或“请慢一点”。
- Повторите和Медленно, пожалуйста不完全一样：前者请对方重说，后者请对方放慢。
- 这些请求中的语法词形先作为整句学习。今天不要求自己推导其他命令式。
- И是一个完整元音。第5天会把它与Ы放在一起比较。

### 练习与答案

1. 【choice】对方问名字，你应选哪种开头回答？
   - 选项：Меня́ зову́т … / Пока́! / нет
   - 答案／参考：Меня́ зову́т …
   - 解析：Меня зовут加名字是介绍姓名的语块。

2. 【choice】要礼貌地引起别人的注意，可以说？

   - 解析：Извините可用于劳驾。

3. 【choice】В与Б中，常见音值为[v]的是？
   - 选项：В / Б
   - 答案／参考：В
   - 解析：В读[v]，Б读[b]。

4. 【choice】Как вас зовут?的意思是？
   - 选项：您叫什么名字 / 我不明白 / 谢谢
   - 答案／参考：您叫什么名字
   - 解析：这是已经学过的姓名问题。

5. 【match】把大写字母与对应的小写字母配成对。
   - 答案／参考：И ↔ и；П ↔ п；Л ↔ л；Д ↔ д
   - 解析：逐个认清字形。大小写表示同一个字母；不要按拉丁字母的读法猜。

6. 【listen】先听俄语，再选择对应的意思或字母。
   - 朗读内容（听力先隐藏）：дэ
   - 选项：Д / Л / П / И
   - 答案／参考：Д
   - 解析：дэ是字母Д的名称。

7. 【choice】你完全没听懂一句话，先说明情况。
   - 选项：Я не понима́ю. / Хорошо́. / Меня́ зову́т …
   - 答案／参考：Я не понима́ю.
   - 解析：这句说明我不明白／听不懂。

8. 【choice】对方说得太快，你希望放慢速度。
   - 选项：Ме́дленно, пожа́луйста. / Пока́! / Спаси́бо!
   - 答案／参考：Ме́дленно, пожа́луйста.
   - 解析：медленно表示慢慢地。

9. 【order】把“请再说一遍”排好。
   - 答案／参考：Повтори́те, пожа́луйста.
   - 解析：请求重复用Повторите，再加пожалуйста。

10. 【order】把“我听不懂”排好。
   - 答案／参考：Я не понима́ю.
   - 解析：完整语块是Я не понимаю。

11. 【choice】Ещё раз.在本课中的意思是？
   - 选项：再一次 / 好的 / 您叫什么名字
   - 答案／参考：再一次
   - 解析：ещё раз表示再一次。

12. 【choice】哪一项按д-о-м的顺序排列？
   - 选项：мод / дом / дмо
   - 答案／参考：дом
   - 解析：从左往右拼读д-о-м。

13. 【listen】先听俄语，再选择对应的意思或字母。
   - 朗读内容（听力先隐藏）：Повторите, пожалуйста.
   - 选项：请再说一遍 / 请慢一点 / 谢谢
